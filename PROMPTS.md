# Prompts utilizados con Inteligencia Artificial

## Emiliano - Módulo de validación de entrada

Prompt:
"Genera en Bash un módulo para un script que reciba exactamente dos argumentos desde la línea de comandos. El primer argumento debe ser una palabra o frase a buscar y el segundo una ruta o carpeta. El programa debe validar que se reciban exactamente dos argumentos y mostrar un mensaje de uso incorrecto en caso contrario. También debe verificar que la ruta proporcionada exista y sea un directorio válido. Agrega comentarios para documentar las partes principales del código."
